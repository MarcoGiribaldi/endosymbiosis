# endosymbiosis.org

Página de la trilogía **Symbiosis · Endosymbiosis · Autopoiesis** (Marco Giribaldi).
Tres secciones, una por libro; cada una con su escena WebGL en bucle (three.js local, sin build ni CDN).

- `index.html`, `style.css`, `app.js`: la página. Textos EN/ES en `app.js` (`TXT`).
- `three.module.min.js`, `three.core.js`: three.js r186.
- `CNAME`: dominio para GitHub Pages (`endosymbiosis.org`). `og.png`: imagen para enlaces compartidos.
- Probar en local: `python3 -m http.server 8765` y abrir http://localhost:8765/
